# LUNEX

### Modern Backpack Loader for Roblox

**LUNEX** is a modern and customizable Backpack Loader for Roblox, designed as a clean and flexible alternative to the default Roblox Backpack.

LUNEX provides a modern interface while allowing developers to easily customize the Backpack's appearance and behavior directly through the `lunex` ModuleScript.

---

## ✨ Features

- 🎒 Modern Backpack interface
- 🎨 Fully customizable colors
- 🔤 Customizable fonts and text styles
- 📦 Configurable inventory slots
- 🔍 Customizable search box
- ⚙️ Easy configuration through ModuleScript Attributes
- 🖥️ Designed for a clean and responsive Roblox UI
- 🚀 Automatically loads when the player joins
